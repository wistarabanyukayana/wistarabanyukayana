# Hi, I'm Wistara 👋

I'm a full-stack engineer and an Informatics Engineering student at [ITS](https://www.its.ac.id), Indonesia. I build software for things that fly and for businesses that don't: ground control systems for a university UAV team, and production web apps for real clients.

## Featured work

**✈️ Flight systems** <sub>(private team repositories)</sub>

- **Bayucaraka GCS**: desktop ground control station for ITS's UAV team. I'm the lead developer and architect.<br><sub>Rust · Tauri v2 · SvelteKit</sub>
- **Veldora Server**: low-latency ground server for airborne video, with WebRTC ingest and supervised inference workers.<br><sub>Go · Pion WebRTC · Python</sub>
- **Bayucaraka GCS (web)**: the team's previous ground control station, with a live map, telemetry and mission control. I was the top frontend contributor.<br><sub>React · TypeScript · OpenLayers · Flask</sub>

**🌐 Web**

- **[Padelix Indonesia](https://padelix.co.id)**: company site with a custom CMS and audit logging. I designed, built and deployed it end to end.<br><sub>Next.js · Drizzle · Neon Postgres · Cloudflare Workers</sub>
- Client sites for a travel agency, an umroh agency, an F&B point-of-sale system and a high school.

**Hardware, security and open source**

- **[TD Wattmeter Suite](https://github.com/wistarabanyukayana/Bayucaraka-TD-Wattmeter)**: reads a commercial wattmeter's LCD bus and streams the readings as live telemetry.<br><sub>Arduino · Electron · Web Serial</sub>
- **[Incident Response Portfolio](https://github.com/wistarabanyukayana/incident-response-portfolio)**: my investigation and takedown of a live phishing site.
- **[DBeaver on Flathub](https://github.com/flathub/io.dbeaver.DBeaverCommunity)**: I help maintain the Flatpak package (55+ commits).
